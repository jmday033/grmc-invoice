Privacy policy

Effective October 5, 2026. GRMC Invoice is a personal tool used only by its owner, with the owner's own Google account.

What it accesses

  • Google Sheets (read-only): the work schedule spreadsheet, to find the owner's assigned shifts.
  • Gmail (compose and read-only): to create an invoice draft in the owner's mailbox, and to check whether a draft for the same pay period already exists. It does not send email.

How data is used and stored

Data is used only to produce the owner's invoice. The OAuth token is stored as an encrypted secret in the owner's private repository's automation settings. Generated invoice files are kept as private workflow artifacts for 14 days. Nothing is sold, shared, or used for advertising, and no data is transferred to any third party except Google and GitHub as needed to run the tool.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
